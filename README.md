## 优惠码的真实情况：现在有没有能用的码

中文网络上挂着「数码荔枝最新优惠码」的页面不少，我核对了几个，要么是别人渠道的专属码而且活动早就结束，要么根本不是给 Windows 用的。这类码的特点是绑活动期，过了期限填进结算页也只会提示无效，白折腾半小时。现在下单，别把希望放在搜索来的码上。

真正能确定省钱的是下面三样，按确定性排序：

1. **活动价**。荔枝商店常年有专区活动，商品页显示的划线价和现价就是当期价格，不需要凑单或者满足什么条件。
2. **会员首单券**。新账号结算时系统自动抵扣，满 29 减 2 和满 39 减 5 两张券二选一，系统会自动挑符合门槛的最高面额那张，不用你手动选。老账号的话，每月 1 日 0 点按会员等级刷新优惠券，去「我的优惠券」里看有没有能用的。
3. **积分和红包**。每月 7 日是会员日，当天消费积分按 1.2 倍算，单日赠送上限 200 分，积分能在积分商店换无门槛券。每笔订单还有红包返现，最低 1 元起，按公众号提示参与就行。

三样叠起来，通常能比页面标价再低一点点。指望打到骨折不现实，操作系统这类商品的利润本来就薄，长期挂一个大额公开码的情况很少见。看到「立减 50%」这种说法，先怀疑一下是不是别的产品的码。

## 按人群给建议：家用、办公和装机店分别买哪个

**家里自用、给学生装机。** 家庭版，不用犹豫。日常上网、看视频、Office 和绝大多数游戏在家庭版上没有任何限制。省下的差价够你加一条内存或者买块硬盘。

## 数码荔枝靠谱吗：授权、售后和退款条款

能核实的部分是这样的。有第三方做过一份核查报告，Eagle 和 IDM 这类软件开发商在自己的官网公示了数码荔枝的授权代理身份，参与公示的有 9 家，原始页面点得开、对得上。公司 2014 年成立，企查查显示正常存续。

这段话有个边界得讲清楚。那 9 家都是软件开发商，Windows 属于微软的零售授权体系，两套链条不是一回事，别把前者的结论直接套到操作系统上。买之前把商品页对授权形式的写法读一遍：是直接发密钥还是绑定到微软账户，是一次性买断还是别的形式，页面写什么就按什么预期。

售后这块官方政策写得很明确。客服只负责安装和注册激活这类基础支持，不负责教你用系统。售后期限跟授权期挂钩，授权期 1 年以上的，最长给 1 年免费售后。

退款是重点。数字化商品不适用七天无理由，官方条款里只有四种情形能在订单生成起 7 个自然日内申请：

1. 激活过程出问题，而且客服已跟开发商确认能回收或销毁已交付的激活码
2. 实际交付比订单显示「处理中」的预期时间晚了 2 个工作日以上，订单还没变成「已完成」
3. 订单状态卡在「订单处理异常」超过 2 个工作日
4. 买错版本，比如 Mac 买了 Windows 版，而且已经重新买了正确版本

符合这四条的，7 个工作日内处理完，钱再 1 到 2 个工作日退回原支付账户。反过来，条款里也列了不退款的情况，最容易被忽略的一条是「不认可商品页展示的规格参数」，官方举的例子是激活设备数量和免费更新时长。也就是说页面写着仅限一台设备，你买完发现要装两台，这不算退款理由。

## 买之前必须弄清楚的几个限制

激活失败要先分清是哪一种。填密钥后弹出错误代码，可能是微软服务器那边的问题，也可能是码本身有问题。前者换个时间段重试或者打微软客服电话通常能过，后者要立刻找荔枝的客服。不管哪一种，动作都要快，退款窗口是订单生成起 7 个自然日，过了这个时间条款上就没有回旋余地。下单后把订单页面和激活报错的截图都留着，这两张图在沟通时比一大段描述管用。密钥如果弄丢了，官方建议先找开发商找回，找回不了再联系客服。

绑定账户和零售密钥的区别，直接决定你以后能不能换机。绑定微软账户的数字许可证跟着账户走，换主板或者换整机之后要重新激活，可能还得联系微软支持说明情况。零售密钥可以转移到新设备，激活时提示已达上限的话走电话激活。OEM 密钥绑主板，主板一换就废。商品页写的是哪一种，就按哪一种规则去预期，别自己想当然。

Windows 10 的授权本身是永久的。买断之后没有年费，同一台设备上重装多少次都行，这一点不用担心。

官方支持结束这件事得说透。2025 年 10 月 14 日之后，Windows 10 不再接收普通安全更新，新发现的漏洞不会修补。继续用不是不能用，但要有心理准备：新版本浏览器和部分软件会陆续停止支持，而某些银行 U 盾和政企客户端反而还只认 Win10，这就是现在还有人买它的原因。硬件达标的话，装完直接用微软的免费通道升到 Windows 11 更划算。升不上去，就把这台机器当内网或者离线设备用，别拿它登网银。

升级有个前提，硬件要过 TPM 2.0 和 Secure Boot 这两关，还要在 CPU 白名单里。2017 年之前的平台大多卡在 CPU 型号上，网上有绕过的办法，但已经出了正版授权的讨论范围，我不建议。

## 常见问题

**Windows 10 的密钥能激活 Windows 11 吗？**
同版本一般可以，硬件要达标。反过来 Win11 的密钥也能激活 Win10。企业版和 LTSC 的授权不能跟零售版混用。

**换电脑还能接着用吗？**
看授权类型。零售密钥可以转移，绑定账户的许可证要重新激活，OEM 密钥跟主板绑定，主板换了就失效。

**是一次性买断还是订阅？**
买断。Windows 10 没有年费，荔枝商店交付的是激活码或授权，不是订阅服务。

**家庭版能升专业版吗？**
能。买一个专业版密钥，在「更改产品密钥」里输入，系统会在线升级，不用重装，文件和已装的软件都保留。

**激活失败了怎么办？**
先留截图，7 个自然日内联系客服处理。超过这个时间，条款上基本没有退款空间，只能自己联系微软支持。

最后给个决策顺序。先确认机器硬件能不能上 Windows 11，能上就买对应版本，装完直接升级。上不去又必须用 Win10，就在家庭版和专业版之间按「要不要加入域和远程桌面」二选一，别为用不上的功能付钱。优惠上，把活动价和首单券拿满就够了，花半小时翻优惠码的收益，还不如用这半小时把重要数据备份一遍。👉 [核对 Windows 10 的最新标价](https://lizhi.shop/products/windows-10?cid=7bbix2xj)
